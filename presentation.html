Good morning/afternoon everyone. Today, I am excited to present our project: the Intelligent Network Intrusion Detection System (AI-NIDS). Modern networks face an unprecedented volume of cyber threats ranging from automated DDoS floods to zero-day malware. Traditional firewalls struggle to catch unknown vulnerabilities. AI-NIDS addresses this critical gap by combining machine learning with real-time heuristic analysis inside a full-stack SOC dashboard.
Problem & Motivation
Legacy NIDS Limitations vs. Modern Cyber Threat Landscape
Legacy NIDS Pitfalls
  • Heavily reliant on static signature databases (Snort, Suricata).
  • Incapable of detecting novel Zero-Day exploits.
  • High rate of false-positives overwhelming security analysts.
Evolving Threat Vectors
  • Domain Generation Algorithms (DGA) used by botnets.
  • Obfuscated WebShells & Remote Code Execution (RCE).
  • High-frequency volumetric DDoS attacks targeting APIs.
The AI Advantage
  • Statistical anomaly detection catches zero-day threats.
  • Supervised learning classifies complex flow feature vectors.
  • Reduces Mean Time to Detect (MTTD) from hours to milliseconds.
Why do we need AI-NIDS? Legacy Intrusion Detection Systems rely on static rule databases. When a new virus or zero-day vulnerability appears, rule databases don't have a signature for it yet. Furthermore, attackers obfuscate code using Base64, randomized hostnames, and encrypted payloads. AI-NIDS bridges this gap by learning statistical patterns of normal network behavior versus attack vectors in real time.

Core Detection Engine
Hybrid AI Engine: Random Forest + Shannon Entropy
Supervised Machine Learning
Random Forest Classifier
  • Config: n_estimators=100, max_depth=15.
  • Targets: Normal Traffic, DDoS, Port Scans, SQL Injection, Malware C2.
  • Vector Inputs: Ports, Packet Size, Entropy, TCP SYN/ACK flags.
  • High interpretability and fast inference (< 3ms/packet).
Unsupervised Heuristics
Shannon Entropy Engine
  • Formula: \( H(X) = -\sum P(x_i) \log_2 P(x_i) \).
  • DGA Threshold (>3.8): Flags randomized botnet hostnames (e.g. x89qzk19.biz).
  • File Packing (>5.3): Flags encrypted malware droppers.
  • Pre-filtering stage validates Allow/Block lists before ML routing.
At the core of AI-NIDS is a two-pronged hybrid engine. First, a Random Forest Classifier trained on network features. Second, Shannon Entropy calculations. Entropy measures data randomness. Legitimate domain names like google.com have low entropy, whereas botnet domains like x89qzk19mva.biz have high entropy. This mathematical check catches zero-day threats instantly.
Module Deep-Dive
Network Traffic & Packet Feature Extraction
Extracted Flow Features Vector

Port Scan Signature Pattern
  • High volume of sequential connection requests across ports.
  • Small packet size (<64 bytes) with minimal payload.
  • Elevated SYN flag ratio indicating probe scans.
DDoS Volumetric Signature Pattern
  • Massive bandwidth spike targeting web ports (80/443).
  • Abnormally high packet count per second.
  • Model assigns threatScore > 90% triggering auto-block.
Our Network Traffic Module ingests packet flows and extracts feature vectors. When a flow enters the pipeline, features like packet size, port ranges, entropy, and TCP flags are fed to our model, producing a classification label and a confidence threat score between 0 and 100%.

Module Deep-Dive
File & Payload Threat Scanner
Static Code & Payload Scanning
  • Remote Code Execution (RCE): Detects eval(), exec(), shell_exec().
  • Obfuscated WebShells: Flags nested base64_decode() & dynamic evaluation.
  • SQL Injection: Scans for UNION SELECT, 1=1--, and database dumps.
  • DOM XSS: Flags unsafe innerHTML & document.write sinks.
Header & Binary Anomaly Check
  • Magic Bytes Verification: Validates file header magic numbers against MIME types.
  • Prevents malicious .exe binaries masquerading as benign .png images.
  • Log Analysis: Ingests .pcap, .log, and .csv files for batch security audits.
Our File & Payload Threat Scanner inspects static files and payload bodies. It performs regex signature scanning to detect RCE routines, WebShell obfuscation, and SQL Injections, while validating magic bytes to catch masqueraded binary executables.
